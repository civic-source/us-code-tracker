# Triage Labels

The engineering skills use five canonical triage roles mapped directly to label strings in `civic-source` GitHub issue trackers:

| Role in skills | Label in `civic-source` | Meaning |
| -------------- | ----------------------- | ------- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate and scope this issue |
| `needs-info` | `needs-info` | Waiting on reporter or domain verification for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified with clear completion criteria, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human judgment, legal/data review, or manual execution |
| `wontfix` | `wontfix` | Out of scope or will not be actioned |
