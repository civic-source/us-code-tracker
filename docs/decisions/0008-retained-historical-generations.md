# Retain reviewed historical compiler generations

Status: accepted for source implementation. Nexus vote `vote-1795585911130-cq0dj6p` selected `append_reviewed_generations` unanimously. Four configured automatic fallbacks left one operationally attributed model family; serving identities were unmeasured. Independent real-diff review and executed checks remain separate requirements.

Compiler and oracle corrections change the recipe bound into historical version identities. Existing approved publisher snapshots and their six version records must remain reproducible and addressable. Replacing their proof files or silently interpreting an old collection as a new generation would lose that provenance.

Preserve original materializations, qualifications and witnesses byte for byte. Append reviewed products under `generations/{recipeSha256}` and bind every approved generation in a small explicit registry. Publisher aliases select exactly one reviewed active generation. An immutable historical collection derives from its three exact reviewed version identities, including their source and recipe pins. Membership and database validation resolve that collection rather than assuming one generation per publisher.

Retained readers validate the exact approved record hashes and serve the retained HTML bytes. Active generation production and replay additionally require the exact current recipe. Thus old evidence remains readable without being claimed as newly produced or requalified. Missing, forged, mixed or unreviewed generations fail closed.

Immutable readers use `/history/collection/{collectionId}/18/{section}/`. Their peer, search, export and citation links stay inside that collection. Existing publisher paths are explicit active-generation aliases with visible collection and recipe identity. Unknown collections or absent members have no current-text fallback. The same shared reader template preserves statutory markup and Pagefind exclusion.

Generate the new six products only after transformer and oracle bytes freeze, from the same retained original ZIPs with new independent full-member witnesses. Keep the old collection history. This source integration does not rewrite or accept the current corpus, revise its tags or checkpoints, or promote a publication. All independent source checks, complete source-diff review, static reader tests and normal protected merge gates remain required.
