## 3. Architecture & Governance Decision Register

1. **Local Workbench & Static Public Reader (`ADR-001`)**:
   - Accepted: All ingestion, canonicalization, graph resolution, and analytical exports run in the local workbench. `@civic-source/web` compiles a 100% static Astro bundle pinned by a single `PublicationManifest` with zero runtime dependency on PostgreSQL, local LLMs, or external live APIs (`FederalRegisterActivity` and `AgencyGuidanceSearch` will consume static precomputed snapshots with graceful offline behavior).
2. **Dual Catalog Adapter — File-Backed Fixture Store + PostgreSQL (`ADR-002`)**:
   - Accepted: Define a clean `ICatalogStore` interface in `@civic-source/types` (or `@civic-source/catalog`) with both a deterministic file-backed implementation (used by unit tests, CI, and lightweight contributor builds) and a PostgreSQL implementation (with SQL migrations and transactional CAS acceptance) plus DuckDB/Parquet analytical projections.
3. **Five Orthogonal Trust Dimensions & Three Temporal Modes (`ADR-003`, `ADR-005`)**:
   - Accepted: Every assertion and enrichment record separates:
     1. `extractionState`: `candidate | verified | rejected`
     2. `editorialReview`: `unreviewed | accepted | disputed | superseded`
     3. `legalAuthority`: `statute | regulation | judicial_opinion | agency_guidance | editorial_material | third_party_interpretation`
     4. `applicability`: `known | conditional | disputed | unknown`
     5. `collectionCoverage`: `complete | partial | failed | not_collected`
   - Temporal queries explicitly select `as_published`, `known_as_of`, or `legally_applicable`, and temporal boundaries carry explicit state (`known | open | unknown | conditional`), precision (`day | month | year | unknown`), basis, and evidence spans.
4. **Dependency DAG with Positive, Collection, and Negative Dependencies (`ADR-004`)**:
   - Accepted: Deterministic cache keys include input content hashes, producer version, schema version, and configuration digest, plus collection and negative dependencies so newly resolved citations or producer fixes invalidate affected artifacts without mislabeling parser fixes as legislative amendments.
5. **Single-Host Fenced Task Acceptance Before External Executors (`ADR-006`)**:
   - Accepted: Implement local `TaskAttempt` leases, generations, and monotonic fencing tokens (`USCT-035`) first; keep `USCT-024` (local Gemma), `USCT-031` (HCK/ACQ adapter), and `USCT-032` (RuleSpec export) modular and non-blocking.
